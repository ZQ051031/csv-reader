A fast, dependency-free CSV parser that returns byte-identical output to csv-reader 1.0.0 — same columns, rows and errors on every input, including broken rows — at about twice the speed. Single-pass, hand-written, no dependencies.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
